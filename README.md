# Character Designer Web Application

โปรเจกต์ปริญญานิพนธ์ สาขาวิทยาการคอมพิวเตอร์ มหาวิทยาลัยเกษตรศาสตร์

## Project Description
เว็บแอปพลิเคชันสำหรับออกแบบและปรับแต่งตัวละคร โดยผู้ใช้งานสามารถเลือกชิ้นส่วนต่าง ๆ เช่น ใบหน้า ทรงผม เสื้อผ้า เครื่องประดับ และพื้นหลัง เพื่อสร้างตัวละครตามความต้องการ
